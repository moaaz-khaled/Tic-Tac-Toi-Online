# 🎮 TicTacToeOnline

A real-time online multiplayer Tic-Tac-Toe game built with **Unity, Netcode for GameObjects, and Unity Relay**. Create a lobby, share a game code with a friend, and compete in a classic game of X and O.

This project explores Unity multiplayer networking, lobby management, player synchronization, and online gameplay.

## 🕹️ How to Play

1. **Create a Lobby:** Host a game and generate a unique join code.
2. **Share the Code:** Copy the code and send it to your friend.
3. **Join the Game:** Your friend enters the code to connect.
4. **Start Playing:** The match begins once both players are connected.

## ✨ Features

- 🌐 **Online Multiplayer** — Real-time gameplay for two players.
- 🔗 **Lobby System** — Create and join matches using a game code.
- 🤝 **Unity Relay Integration** — Connect players through Unity Relay without requiring direct peer-to-peer connectivity.
- 🔄 **Player Synchronization** — Coordinate gameplay between connected players.
- 🏆 **Live Score Tracking** — Track each player's performance across rounds.
- 🎯 **Winning Line Highlight** — Highlight the winning combination.
- 🎉 **Victory Screen** — Display match results.
- 🔁 **Play Again Voting** — Both players agree to start another round.
- ⚖️ **Alternating Starting Player** — Switch between X and O as the starting player.
- 🖱️ **Simple Controls** — Click or tap an empty cell to place your mark.

## 🛠️ Tech Stack

- **Engine:** Unity
- **Language:** C#
- **Networking:** Netcode for GameObjects (NGO)
- **Connectivity:** Unity Relay
- **Version Control:** Git & GitHub

## 🧠 Technical Challenges & Lessons Learned

Developing this project provided hands-on experience with:

- Integrating Unity's multiplayer networking stack.
- Establishing online connections using Unity Relay.
- Managing multiplayer game flow, player turns, and round transitions.
- Synchronizing gameplay state between two connected players.
- Handling lobby creation, joining, and rematch coordination.
